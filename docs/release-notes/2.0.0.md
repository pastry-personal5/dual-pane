# Dual Pane 2.0.0

Status: Active

Dual Pane 2.0.0 introduces side-by-side browsing: each Browser independently lists and navigates a real directory.

- Use two compact, dark native panes in one macOS window.
- Browse directories concurrently while retaining the last successful listing after an access failure.
- Select entries, enter folders and folder links, and return to the logical parent in either pane.

File operations are not included in this release.
