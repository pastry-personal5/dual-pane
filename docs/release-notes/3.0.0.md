# Dual Pane v3.0.0

Status: Active

Version v3.0.0 adds tabbed file management, safe file operations, durable workspace restoration, live folder refresh, image previews, and a redesigned Settings Window.

- Organize work with Browser tabs, history, editable Favorites, and restored workspace sessions.
- Copy, move, rename, create, Trash, and permanently delete items with confirmation and recovery safeguards.
- Refresh watched folders automatically, filter hidden items, preview images, and customize keyboard shortcuts.
- Use the frameless macOS window with a draggable Sidebar title row and `Control+Command+F` full-screen toggle.
