# Dual Pane 1.0.0

Status: Active

Initial release of Dual Pane for macOS, with a Qt desktop window for browsing a real directory in one pane.

- Read directory listings on a worker thread and show access errors without discarding the last successful listing.
- Select entries, enter folders and folder links, and navigate to the logical parent.
- Provide platform-neutral domain, application, and adapter crates for listing, selection, navigation, and error handling.

The second pane and file operations are not included in this release.
