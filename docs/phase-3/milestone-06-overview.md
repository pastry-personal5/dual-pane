# P3-M6: Deliver tabbed browser UI

Status: Planned

This milestone connects the P3-M5 tabbed Workspace to the macOS desktop interface. Both Browsers gain interactive tabs, history, Sidebar Favorites, folder sort and summary controls, and the agreed focus and selection behavior. The [architecture plan](milestone-06-architecture.md) describes the implementation boundary; this checklist defines completion.

## Scope and fixed inputs

Follow the [P3-M4 interaction contract](milestone-04-overview.md#decision-sources-and-consumers), [P3-M5 state and request contract](milestone-05-architecture.md), [planned GUI rules](../ux-gui.md#planned-phase-3-gui-decisions), [planned containment](../ux-information-architecture.md#planned-phase-3-containment), [canonical names and action IDs](../ux-terms.md), and [architecture boundaries](../architecture.md#3-boundary-ownership). Keep the P3-M2 settings and Favorites storage format and existing action IDs compatible. The application owns tab, Favorites, selection, and sort decisions; widgets show those decisions and submit UI-neutral gestures.

In scope: tab creation, activation, closure, drag reordering, labels and full-path descriptions; Back, Forward, Up, and manual Refresh; Sidebar Favorite Group and Item editing, movement, launch target probing, and activation; five Folder Items columns, eight direct sort buttons, responsive hiding, Folder Pane summary, and the narrow-Browser overlay; multi-selection, cursor, scroll, focus, keyboard access, accessibility, and command enablement for the controls delivered here. The Path Edit Control continues to display the confirmed path without accepting typed navigation. Add the Notices Button, current-session error messages, and the explicit storage-recovery action according to the [Notices handoff](milestone-06-architecture.md#notices-handoff). The separate Settings window and shortcut editor remain future work; the existing disabled Settings control does not become the storage-recovery entry point.

Out of scope: file-operation commands, inline file-name editors, Operation Panels, and operation Notices (P3-M7/P3-M8); saved tab-session restoration, routine Notices startup opening and its preference (P3-M9); and native file-system watching (P3-M10). Actionable storage errors open Notices at startup in M6. Do not add a dependency or build tool without the approval required by [AGENTS.md](../../AGENTS.md#dependencies-and-licensing).

Native verification remains an owner decision if the execution environment has no display: record the exact blocker, leave the native-verification item unchecked, and ask the owner whether a documented exception may satisfy the milestone. The implementer does not decide that exception.

## Completion checklist

- [ ] Each Browser renders its ordered tabs and active tab independently. New Tab, tab activation, close button, `Command+T`, `Command+W`, and drag reordering use the P3-M5 commands; closing the final tab shows a clean Home tab. Labels, full-path tooltips and accessibility text, hover-only Close Tab Buttons, and nearest-right-then-left activation match the GUI rules. Tests cover both Browsers and same-name tabs.
- [ ] Back, Forward, Up, Favorite activation, `Option+Left Arrow`, `Option+Right Arrow`, and `Command+R` target the correct active tab. The Path Edit Control remains read-only, displays that tab's confirmed path, and does not receive keyboard focus. Disabled navigation controls reflect available history and parent location; pending, failed, and superseded reads leave the last successful view and summary paired with its confirmed path. Refresh and navigation failure feedback stays visible without replacing that listing. Tab and history switches restore matching selection, cursor, and scroll.
- [ ] Sidebar Favorites render ordered groups and items from application output. Group creation, inline rename, menu movement and deletion, Item addition from the active folder, inline alias edit, pointer-only Item Context Menu, drag reorder and cross-group move, and Item activation all reach application commands. Rejected empty, whitespace-only, duplicate, or stale edits leave the committed hierarchy unchanged and produce inline feedback without adding a Notice; invalid inline names retain editor focus. An accepted edit remains in memory if its save fails, with recoverable storage feedback. Tests cover cross-group duplicate aliases and deletion of a group with children.
- [ ] Launch probes run off the GUI thread after Favorites have loaded or been seeded. A completed unavailable result removes only the still-matching Item, requests a durable save, and adds a Notice naming it; failed or cancelled probes cannot prune Favorites. Tests cover edits or deletion while a probe is in flight, settings-load failure, and an intentionally empty collection.
- [ ] Folder Items show Name, Type, Relative Date, Exact Date, and Size in the specified order and formats, with unavailable metadata as `—`. Row #2 shows the last successful visible listing's count, selection count when applicable, and non-recursive known-size total or `—`. The eight direct sort controls show the effective location-shared choice and update every open tab at that byte-exact location, including inactive tabs. A delayed sort click cannot change another tab's remembered choice. Responsive column and control hiding follows the specified order; the `Expand` overlay appears below 280 pixels without consuming commands.
- [ ] Mouse and keyboard selection match the planned Command-click, Shift-click, Shift-arrow, Command+A, right-click, and plain-movement rules. Qt row selection, current index, and scroll reflect application state without feedback loops or retargeting after a tab switch or row delta. Browser focus entry activates that Browser; `Option+F`, Full Keyboard Access traversal, tab and Favorite arrow/Return behavior, and text-editor shortcut priority work without changing the other Browser's view state.
- [ ] Delivered controls have the canonical accessible names, useful full-path descriptions, tooltips, keyboard access where specified, and visible enabled states. A settings migration moves the existing workspace `Command+W` binding from `CloseWindow` to the new `CloseTab` action without reusing or renaming either ID; `CloseWindow` retains its meaning. The workspace `Command+W` closes a tab, `Command+Q` quits, and a focused Notices window closes with `Command+W`. Tests cover fresh and upgraded settings without shortcut collisions.
- [ ] The Notices Button opens a current-session window that shows storage and Favorite probe failures and automatic removals without blocking browsing. Actionable storage failures open Notices even at startup. A storage error offers Reset Settings, which requires explicit confirmation with Cancel as the default, preserves the failed database, reloads fresh settings after success, and reports success or failure; a cancelled reset leaves it untouched. Reset remains available after a database-open failure and cannot apply an older queued save afterward. Tests cover load, save, worker-start, corrupt/newer-schema, reset-preservation, stale-save, and reset-failure paths without real user data. Later milestones add operation and restoration messages and the routine startup preference.
- [ ] Qt-free adapter and desktop-session tests cover stable-ID command routing, rejected Favorites edits, sort/tab changes during input, inactive-tab updates, and selection/scroll restoration. Native macOS verification covers rendered tabs, five columns, Sidebar editing, drag gestures, focus and Full Keyboard Access, responsive hiding, accessibility names, and both `Command+W` window contexts. If the environment has no display, record the exact blocker and leave this item unchecked pending the owner decision noted above. All file-system tests use temporary directories.
- [ ] Directly affected product, UX, README, and plan docs reflect the delivered behavior. `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, and `make check` pass before P3-M6 is marked Done; any unavailable gate leaves this item unchecked with the exact blocker recorded.
